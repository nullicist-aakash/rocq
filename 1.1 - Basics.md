# Functional Programming in Rocq
## Structures

```
Inductive day : Type :=
  | monday
  | tuesday
  | wednesday
  | thursday
  | friday
  | saturday
  | sunday.
```


## Functions

```
Definition next_working_day (d:day) : day :=
  ...
```

## Statements

```
match d with
  | monday ⇒ tuesday
  | tuesday ⇒ wednesday
  | wednesday ⇒ thursday
  | thursday ⇒ friday
  | friday ⇒ monday
  | saturday ⇒ monday
  | sunday ⇒ monday
  end.
```

## Examples
### Compute
```
Compute (next_working_day friday).
```

### Example
```
Example test_next_working_day:
  (next_working_day (next_working_day saturday)) = tuesday.
```
